# Offensive Security Basics — Week 3 Notes
## What Is Offensive Security?
A proactive approach to cybersecurity: thinking like an attacker to find vulnerabilities *before* malicious actors do. Contrasts with defensive security, which focuses on protecting systems and responding to threats.
**Analogy:** defensive security = better locks and cameras. Offensive security = hiring a reformed burglar to show you where your locks are weak.
## Why It Matters
- **Proactive risk management** — find issues before they're exploited
- **Real-world testing** — simulates actual attack scenarios
- **Compliance** — many industries require regular security assessments
- **Cost-effective** — fixing a vuln is cheaper than recovering from a breach
## Specializations in the Field
| Area | Focus |
|---|---|
| Penetration Testing | Systematic testing of specific systems/apps, structured methodology, detailed reports |
| Red Teaming | Long-term simulation of advanced persistent threats — tests people, process, and tech |
| Bug Bounty Hunting | Independent researchers find vulns for rewards, continuous crowd-sourced testing |
| Security Research | Building proof-of-concept exploits or discovering new vulnerabilities |
