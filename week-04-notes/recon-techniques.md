# Week 4 - Reconnaissance Techniques

## Passive Recon
- OSINT: gathering info without touching the target
- Google dorking: using search operators to find sensitive info
- WHOIS: finding domain registration details
- Shodan: search engine for internet-connected devices

## Active Recon
- Port scanning: sending packets to find open ports
- Open: port is accepting connections
- Closed: port exists but nothing is listening
- Filtered: firewall is blocking the port

## Common Ports
- 22 = SSH
- 80 = HTTP
- 443 = HTTPS
- 21 = FTP
- 3389 = RDP
